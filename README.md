# Famous Last Words at 1 Percent

One line (104 characters) — the funniest last words a phone says as its battery hits 1 percent.

> I saved my last spark just to tell you this: your screen-time report drops tomorrow, and it is not kind.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
